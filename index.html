SonaLoop

A local exporter for your 360sona display cases.

  1. Paste a published widget link or iframe. You can also import a saved widget HTML file or a SonaLoop JSON snapshot.
  2. Load the preview to see the source settings. Choose a format and resolution.
  3. Export. MP4 repeats are baked into the video; GIF can repeat forever or use your repeat count.

Synchronized loop: plays the loaded animation once for each full turn, if turntable is enabled. An Alive/random playlist uses the currently loaded idle for a repeatable cycle. The source clip itself must be loopable for a seamless pose transition.

Natural recording: follows the live site's animation, expressions, timing, playlist and prop actions. It does not alter rotation speed or guarantee a seamless ending.

Snapshots preserve the public avatar and config, but assets still load from 360sona. No website login or Python installation is needed. MP4 cannot carry transparency; GIF has limited colors and hard transparency edges.

Website renderer changes may require an app update. SonaLoop is not affiliated with 360sona or Microsoft.
